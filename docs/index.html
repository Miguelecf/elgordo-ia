human-led engineering workflow

ElGordo IA

Plan fat. Execute thin. Test without mercy.

OpenCode conversa. ElGordo gobierna el estado. OpenSpec versiona el contrato. El humano decide en cada punto importante.

the_flow

Una ruta. Tres compuertas humanas.

/eg-> plan-> human: seal-> execute-> human: review-> QA-> human: approve-> done

El conductor consulta elgordo status --json, delega un solo rol segun la fase y se detiene en cada compuerta. Un defecto vuelve a ejecucion; un problema de alcance vuelve a planificacion.

the_authority

Una responsabilidad por capa.

Human requisitos, arquitectura y aprobaciones.
ElGordo fases, transiciones y sellos.
OpenSpec propuesta, diseno, tareas y specs versionados.
Engram continuidad, nunca autoridad.

the_contract

Lo aprobado queda sellado.

Antes de ejecutar, el plan y los Markdown de OpenSpec se convierten en un manifest SHA-256. Si cualquiera de ellos cambia, la CLI bloquea la siguiente transicion: se requiere replan.

$ elgordo plan hash # revisa el contrato $ elgordo plan seal --expect sha256:<hash> # ejecucion habilitada

the_roles

Especialistas, no agentes omnipotentes.

Questioner aclara solo lo necesario.
Planner crea el plan y OpenSpec.
Executor implementa con TDD.
QA verifica de forma independiente.
ElGordo IA MVP. El humano conserva el control.
